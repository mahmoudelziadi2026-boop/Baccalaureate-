# Baccalaureate Organizer

واجهة تعليمية تفاعلية لكتاب **English Egyptian Baccalaureate Part 1**. يضم المشروع الصفحة الافتتاحية وقارئ الدروس، ونصوص القراءة والاستماع، والترجمة العربية عند الطلب، وتتبّع القراءة، وأسئلة فهم وتدريب رأي/سبب/دليل.

## التشغيل محلياً

يتطلب المشروع **Node.js 22+** و`pnpm`.

```bash
pnpm install
pnpm dev
```

بعد ذلك افتح الرابط الذي يظهر في الطرفية، وغالباً يكون `http://localhost:3000`.

## ما يتضمنه المستودع

| المسار | المحتوى |
|---|---|
| `client/src/pages/Home.tsx` | الصفحة الافتتاحية ومنظّم الوحدات |
| `client/src/pages/Reader.tsx` | قارئ الدروس والترجمة والأسئلة والصوت |
| `client/src/data/` | بيانات الدروس والأسئلة والتوقيتات والدليل النصي |
| `client/public/assets/` | الشعارات وصور الوحدات وملفات الاستماع المحلية |

## ملاحظات

يحتوي المستودع على الأصول اللازمة للتشغيل المحلي؛ لذلك تعمل صور الوحدات والتسجيلات داخل نسخة Vite دون الحاجة إلى روابط تخزين خارجية. تُحفظ إجابات الطالب وتفضيل الوضع الليلي محلياً في المتصفح عبر `localStorage`.
